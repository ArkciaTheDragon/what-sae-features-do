# What Does a Sparse Autoencoder Feature Do? A Weight-Based Account

This package contains the data-computation code for the paper's three experiments and appendix analyses.

## Installation

Use Python 3.13 or later.

```bash
uv sync --frozen
uv run sae-weight-analysis --help
```

The model checkpoints are loaded from Hugging Face or from a directory supplied with `--model-path`.
SAEs are loaded through SAE Lens.

| Model | Checkpoint | SAE release | Width |
|---|---|---|---|
| Gemma-2-2B | `google/gemma-2-2b` | `gemma-scope-2b-pt-res-canonical` | 16,384 |
| Gemma-2-9B | `google/gemma-2-9b` | `gemma-scope-9b-pt-res-canonical` | 16,384 |
| Llama-3.1-8B | `meta-llama/Llama-3.1-8B` | `llama_scope_lxr_8x` | 32,768 |

Model access uses the standard Hugging Face authentication settings.
The model, SAE, layer, and calibration settings are defined in [config.py](sae_weight_analysis/config.py).
Commands use all paper layers by default and accept `--layers` for a selected subset.
Run the sections below in order to generate the experiment outputs.
The comparison, intervention, and judge commands read the semantic and attention outputs generated by the preceding commands.

## Experiments 1 and 2

```bash
for model in gemma-2-2b gemma-2-9b llama-3.1-8b; do
    uv run sae-weight-analysis semantic --model "$model"
    uv run sae-weight-analysis attention --model "$model"
done
```

## Experiment 3

```bash
for model in gemma-2-2b gemma-2-9b llama-3.1-8b; do
    uv run sae-weight-analysis compare --model "$model" --projection dec_u
    uv run sae-weight-analysis compare --model "$model" --projection enc_e
done
```

## Interventions

```bash
for model in gemma-2-9b llama-3.1-8b; do
    for role in semantic query key; do
        uv run sae-weight-analysis intervene --model "$model" --role "$role"
    done
done
```

`NEURONPEDIA_API_KEY` supplies an API key when used.
Prompts are obtained from Neuronpedia and cached under `output/prompt_cache`.

## LLM judge

Serve Llama-3-70B-Instruct through an OpenAI-compatible endpoint supporting `guided_choice`.

```bash
for model in gemma-2-2b gemma-2-9b llama-3.1-8b; do
    uv run sae-weight-analysis judge --model "$model" \
        --endpoint http://127.0.0.1:8000/v1 \
        --judge-model meta-llama/Meta-Llama-3-70B-Instruct
done
```

`JUDGE_API_KEY` supplies endpoint authentication when used.

## Appendix analyses

```bash
uv run sae-weight-analysis normalization --model gemma-2-9b
uv run sae-weight-analysis alignment --model gemma-2-9b
uv run sae-weight-analysis alignment --model llama-3.1-8b
```

Semantic metric ablation and threshold sensitivity are included in the semantic command.
Saved semantic metrics can be aggregated again with `summarize --model MODEL`.

## Output layout

Each model has `semantic`, `attention`, `comparison`, `intervention`, `judge`, `alignment`, and `normalization` output directories.
Command settings are recorded in the model's `runs` directory.
`--output` selects the output root, `--device` selects the compute device, and `--dtype` selects the model precision.
The default precision is float32.
